# 浮譯 ScreenLingo

以 Pixel 5 為優先的 Android 原生螢幕翻譯 App，最低 Android 11。0.1.8 修正全螢幕遊戲底部選單被誤當成隱藏導覽列而略過的問題，並改善離線模式對彩色／描邊遊戲選單的漏讀：保留原圖辨識結果，再用分區掃描、字色分離及小字放大補漏，並拆開相鄰按鈕。保留 0.1.7 移除遮畫面提示的修正。保留貼邊半球與橫直向切換持續錄影。預設按半球擷取目前畫面，再透過 Google App 公開的圖片分享入口開啟 Google 智慧鏡頭；使用者在 Google 畫面按「翻譯」，選擇中文（繁體）或其他目標語言。需要網路，截圖交給 Google 線上處理。保留原本的離線原位覆蓋，可在「翻譯方式」切換。

## Google 智慧鏡頭模式（預設）

1. 安裝或更新 Google App，確保網路可用。
2. 啟用浮譯並允許顯示在上層、擷取整個螢幕。
3. 切到遊戲，按懸浮球；浮譯先隱藏懸浮球與錄影計時，再擷取一張畫面。
4. 切到 Google 智慧鏡頭後，按「翻譯」，在 Google 畫面選「中文（繁體）」或其他目標語言。
5. 返回原本的 App 後，可操作遊戲並再次按球擷取新畫面。

此模式使用實際安裝的 Google App 所公開的 `ACTION_SEND image/png` 智慧鏡頭入口，不使用 Samsung 的系統手勢，也沒有私人自動翻譯參數或自動點擊。Google 介面、語言選擇及辨識結果由 Google App 決定，無法保證每個字都能翻譯；不是即時連續翻譯。找不到智慧鏡頭入口時會明確顯示錯誤，不會改傳其他服務。浮譯的語言模型與下方原文／目標設定只用於離線模式。

截圖以 PNG 暫存在 App 私有 `cache/lens/`，使用 FileProvider `content://` 與臨時讀取權限交給 Google App；不授予寫入權限，不寫入相簿。下次分享時刪除超過 24 小時的暫存；也可從 Android 應用程式設定清除快取。交給 Google 後的線上處理適用 Google 的服務政策。這與原本離線模式只在記憶體處理畫面不同。

常駐關閉時，成功開啟智慧鏡頭後就停止浮譯擷取；正在錄影時仍保持服務。內建錄影會錄到切換 Google 畫面的過程，轉向後繼續同一段影片，手動停止才儲存。另一個錄影 App 仍無法同時取得 MediaProjection。

## 已實作

- 啟用／停止螢幕擷取與懸浮球；通知列可直接停止。
- 平常呈半球貼在左右安全邊緣；拖曳時顯示整顆，放手後吸附最近一側並記住高度。設定不透明度 25–100%、完整圓直徑 40–72 dp，停靠時可見寬度為一半；點按與長按選單維持。
- 常駐模式；也可切換單次模式，看完一次譯文後停止。
- 離線模式預設繁體中文；手機偏好語言會優先列出（限翻譯引擎支援），亦可選其他支援語言。智慧鏡頭模式在 Google 畫面選語言。
- 內建英文試譯頁，可在離線環境練習懸浮翻譯。
- 內建中、英／拉丁字母（包含法文）、日、韓、天城體 OCR；可另行下載泰文辨識模型，自動選擇或手動指定。
- 原位覆蓋譯文，背景色取樣，長句縮字，點譯文顯示原文、全文與複製按鈕。
- CJK 遊戲文字放大辨識會補充原圖結果；拉丁字母／天城體則保留完整段落，避免單一補漏詞取代整句；遇到較弱的辨識結果，會額外掃描重疊區域、分離明亮／彩色字的描邊。清楚的高信心文字及空白區會略過額外辨識。這是通用影像處理，沒有內建特定遊戲的文字或座標。
- 小字會以放大影像再次辨識；密集的技能標題、條件與角色名會依位置及字色分段，譯文嚴格限制在原文字框，避免互相覆蓋。長按懸浮球可選「檢視全部譯文」。
- 翻譯後可雙指放大至 4 倍、縮小回 1 倍；放大後單指拖曳。底圖與譯文同步縮放，仍可點譯文看全文。
- 內建螢幕錄影：與 OCR 共用單一擷取授權／虛擬螢幕，錄下原畫面、懸浮球及譯文覆蓋；可選錄遊戲／媒體播放聲音，不使用麥克風。MP4 儲存在相簿 `Movies/ScreenLingo`。
- 「選擇及下載語言模型」分開列出辨識及翻譯模型，可多選翻譯語言、查看狀態、下載及刪除。中文繁簡共用模型，英文已內建。支援只用 Wi-Fi 下載。
- 離線模式螢幕影像只存在記憶體；還原即釋放。智慧鏡頭模式暫存 PNG 並交給 Google 線上處理；不使用自建伺服器。錄影是另外由使用者啟動並存入手機的功能。
- 無廣告、無需 API key、未使用無障礙服務。

## 離線模式安裝與操作

若要使用原本的離線覆蓋，先在設定「翻譯方式」選擇「浮譯離線翻譯（原位覆蓋）」，再依以下步驟操作。

1. 將提供的 APK 傳到手機並開啟。Android 詢問時，允許該檔案來源安裝未知應用程式。
2. 開啟「浮譯 ScreenLingo」。先連上 Wi-Fi，建議預先下載原文／目標語言模型。
3. 按「啟用懸浮翻譯」，允許「顯示在其他應用程式上層」，並在系統對話框允許擷取整個螢幕。
4. 回到要閱讀的 App，按「譯」懸浮球。首次某個原文語言可能另需下載模型。
5. 譯文會遮住原文。雙指往外拉可放大，放大後可單指拖曳，往內捏可縮小。點某一段看全文；點空白或「×」懸浮球還原。
6. 還原後可正常捲動與操作原 App，再按一次重新翻譯。
7. 長按懸浮球開啟設定或停止；也可從常駐通知停止。

若只用 Wi-Fi 下載已開啟，沒有模型且未連 Wi-Fi 會等待或顯示模型未備妥。模型備妥後可離線使用該語言組合。自動偵測可能對短句不準，請手動設定原文語言。

## 錄下遊戲與浮譯操作

1. 在設定選擇是否「錄製遊戲聲音（不錄麥克風）」，預設關閉。開啟時需允許 Android 音訊權限；程式只建立 `AudioPlaybackCaptureConfiguration`，沒有麥克風音源。
2. 啟用懸浮翻譯，切到遊戲並先調整橫／直向。長按「譯」球，選「開始錄影（可同時翻譯）」。也可從設定頁開始錄影。
3. 畫面會出現紅色計時鈕，可照常按球翻譯、雙指縮放、還原並操作遊戲。
4. 點紅色計時鈕、長按球選「停止錄影並儲存」，或從常駐通知停止錄影。停止錄影後仍可翻譯；正常關閉浮譯時也會先結束並儲存錄影。
5. 到相簿 `Movies/ScreenLingo` 查看 MP4，或在設定按「播放最近一次錄影」。安裝新版不會刪除已存影片。

影片為 H.264，最長邊最多 1920 px、最高目標 30 fps、視訊約 5 Mbps；有聲時另加 AAC。開錄時固定編碼器、ImageReader 及 VirtualDisplay 尺寸，錄影中轉向時保持相同 Surface 與單一影片。Android 12L 以上會將新方向內容等比置中並補黑邊；例如橫向開錄後切到直向智慧鏡頭，直向畫面出現在影片中央，返回遊戲後恢復橫向填滿。錄影計時不歸零、音訊不重建，控制鈕會依新方向重新定位。按球截圖會移除錄影畫布產生的黑邊並還原當前螢幕比例，供智慧鏡頭或離線覆蓋使用。

按翻譯擷取畫面的瞬間，單一虛擬螢幕會暫時將輸出切至 ImageReader，再接回編碼器，影片可能有短暫停格，之後的辨識與翻譯在背景執行。影片外框保持開錄時的方向，不會在同一影片內改變編碼解析度；Google 智慧鏡頭介面本身的方向仍由 Google 控制。

部分遊戲會禁止播放音訊擷取，這時影片可能沒有遊戲聲音。內建錄影無法與 XRecorder 等另一個 MediaProjection 錄影同時使用；若另一個擷取工作接管或系統撤銷擷取，浮譯會嘗試結束並儲存當前影片。強制終止程序／斷電無法保證儲存；錄影太短、空間不足或編碼失敗時，不會將未完成檔案當成成功影片發佈。錄影期間暫時保持懸浮球，單次模式不會因還原譯文而中斷錄影。

泰文畫面：進入「選擇及下載語言模型」，下載上方「泰文文字辨識模型」（約 1.1 MB），再勾選下方泰文、中文翻譯模型並按底部下載。回設定將目標設為繁體中文；文字種類可選自動或泰文，主要讀泰文時建議指定泰文。自動辨識採保守門檻，畫面不清楚或短句誤判時請指定泰文。泰文辨識模型使用 Android 下載管理員，下載後比對固定版本的大小與 SHA-256，通過後才安裝到 App 私有資料夾；可取消、刪除及重試。背景下載完成後，下次開啟模型頁或翻譯時完成驗證。

只有新增語言且本機缺少模型時才會下載。其他等待時間是擷取、辨識、載入與翻譯；同一次常駐期間會重用翻譯器及近期譯文。如果主要閱讀日文，可同時指定原文為日文、文字種類為日文，避免每次自動跑五種 OCR。

## 行為與限制

- 這是一層暫時的翻譯閱讀畫面。**不會修改其他 App 本身的內容，也不會即時追蹤捲動或影片。** 覆蓋時觸控由翻譯層接收；先還原，再操作原 App。
- 系統返回鍵在模擬器中，從全文視窗返回覆蓋後未能穩定還原；本版請用「×」半球或空白處還原。此問題未列為已修復。
- 文字框很小或譯文很長時會縮小字體，極端情況顯示省略號，點該段可看全文。
- 相簿中的遊戲照片若本身顯示很小，覆蓋字也會保持原圖大小。可先放大照片，或長按球查看全部譯文。放大 OCR 無法補回原圖已遺失的字形細節；圖示仍可能被誤認成數字，遊戲術語也可能被離線引擎誤譯。
- 複雜遊戲畫面因多次補漏，會比一般文字需要更長辨識時間；不是每次重新下載模型。濃厚描邊、壓縮影像仍可能漏讀或讀錯，例如實測藍色「対戦」及禮物按鈕文字未穩定辨識。翻譯本身也可能誤譯遊戲術語；這版沒有宣稱與 Google 智慧鏡頭相同品質。
- 背景使用文字框邊緣的中位數顏色，對純色較自然；圖片、漸層、複雜排版不會像修圖軟體般無痕還原。
- OCR 的文字種類與可翻譯語言不同。本版可讀拉丁字母／中／日／韓／天城體，加上另行下載的泰文；仍不能 OCR 阿拉伯、西里爾等字形，但它們可能是可選的輸出語言。泰文辨識採 Tesseract，清晰印刷文字較適合；花體、低解析或複雜遊戲背景仍可能誤認。
- 系統狀態列、鍵盤與安全視窗可能不允許其他 App 覆蓋；部分 App（例如部分系統設定頁）會主動隱藏懸浮球，切回一般 App 即可。禁止擷取的銀行、DRM 等畫面無法讀取。
- Android 必須由使用者授權螢幕擷取，並會顯示系統指示與常駐服務通知。重開機不會自動恢復授權。
- 鎖定畫面、系統停止／回收服務、另一個 App 開始擷取後，可能需要重新啟用。辨識中旋轉螢幕會取消舊畫面的顯示工作，請在新方向再按球；錄影會繼續。閱讀時旋轉會還原譯文。
- 閒置時會將擷取 Surface 脫離虛擬螢幕；按下懸浮球才接回並讀取新影格，並非持續執行 OCR。
- ML Kit 提供機器翻譯，品質依語言而異；繁體中文為中文翻譯結果經 ICU 簡轉繁，並非專門的台灣用語模型。
- Google SDK 可能為模型下載、更新或診斷而連線。離線模式不保存截圖／翻譯歷史；智慧鏡頭模式會暫存並將截圖交給 Google，詳見上方說明。使用者主動啟動的錄影會將畫面及所選音訊存到手機。

## 建置

需要 JDK 17、Android SDK Platform 35 / Build Tools 35.0.0。用 Android Studio 開啟此資料夾，或：

```powershell
$env:JAVA_HOME = '你的 JDK 17 路徑'
$env:ANDROID_HOME = '你的 Android SDK 路徑'
.\gradlew.bat assembleDebug testDebugUnitTest lintDebug
```

Pixel 5 輸出：`app/build/outputs/apk/debug/app-arm64-v8a-debug.apk`；x86_64 版本供模擬器使用。此交付版為 debug 簽署測試版，未上架 Google Play。若要公開發佈，需自行管理正式簽章、檢查最新平台政策並完成實機驗收。不要將正式簽章金鑰提交到專案。

## 原始碼導覽

- `MainActivity.java`：設定、權限與語言模型管理。
- `ModelsActivity.java`、`TranslationModelJobs.java`：多選下載、模型狀態及刪除。
- `OcrModels.java`、`ThaiOcr.java`：可選泰文辨識模型、校驗下載、Tesseract 座標與段落。
- `OcrEnhancer.java`：通用彩色字區域、明亮字二值化、重疊分區及描邊處理。
- `OverlayService.java`：前景服務、懸浮球、覆蓋閱讀層與完整譯文視窗。
- `LensShare.java`：選擇 Google 公開的智慧鏡頭圖片分享入口，PNG 私有快取與臨時 FileProvider 讀取權限。
- `ScreenCapture.java`：單次授權對應單一虛擬螢幕，閒置時斷開 Surface，錄影時在編碼器及單次 OCR 擷取之間切換輸出。
- `ScreenRecorder.java`：MediaCodec H.264／AAC、遊戲播放音訊、MediaMuxer 與 MediaStore 原子完成影片。
- `TranslationEngine.java`：OCR 模型選擇、語言偵測、翻譯與繁簡轉換。
- `TranslationOverlay.java`：座標映射、背景遮罩與字體縮放。
